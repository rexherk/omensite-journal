Bring your TopstepX trades into OmenSite Journal.

How to import your TopstepX trades

  1. In TopstepX, select the account you want to export.
  2. Open the Trades tab at the bottom, then select Export.
  3. Choose the date range and select Export again to download the file.
  4. In OmenSite Journal, open Import and upload the CSV file.
  5. Select the matching Journal account and choose Preview. Check the trades, dates, times, and fees.
  6. If the preview looks right, click Add to the journal.

Export one account at a time. For later imports, avoid overlapping date ranges, since repeated fills can create duplicates, and keep all fills for a position together.

If you see Unrecognized columns, don’t add the file yet; keep the original and ask for help. If the account isn’t listed, add it under Settings → Accounts → Add account.
